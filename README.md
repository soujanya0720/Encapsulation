# Private Variable in Java

## Description
This project demonstrates the concept of **encapsulation** in Java using a private variable and public getter and setter methods.

## Concepts Used
- Classes and Objects
- Private Access Modifier
- Encapsulation
- Getter and Setter Methods
- User Input using `Scanner`

## How It Works
1. The user enters an account balance.
2. The `setbalance()` method stores the value in the private `balance` variable.
3. The `getbalance()` method returns the stored balance.
4. The program displays the account balance.

## Sample Output
```text
5000
Balance:5000
```

## How to Run
1. Save the file as `Private.java`.
2. Compile the program:
   ```bash
   javac Private.java
   ```
3. Run the program:
   ```bash
   java Private
   ```

## Learning Outcome
Understand how encapsulation protects data and how private variables can be accessed through public methods.
